# ChronoSwap

เว็บแลกเปลี่ยนทักษะด้วยธนาคารเวลา สำหรับเปิดใช้บนเครื่องส่วนตัวหรือเซิร์ฟเวอร์ภายใน

## เปิดเว็บบน Windows

1. ติดตั้ง Python 3.10 ขึ้นไป
2. ดับเบิลคลิก `start.bat` หรือเปิด PowerShell ในโฟลเดอร์นี้แล้วรัน `python server.py`
3. เปิด `http://127.0.0.1:8000`
4. หยุดเว็บด้วย `Ctrl+C` ในหน้าต่างเซิร์ฟเวอร์

เว็บใช้ Python standard library และ SQLite ที่มีมากับ Python จึงไม่ต้องติดตั้งแพ็กเกจเพิ่ม ฐานข้อมูลจะถูกสร้างที่ `data/chronoswap.sqlite3` และเก็บข้อมูลต่อเนื่องเมื่อปิดเปิดเว็บใหม่

## บัญชีตัวอย่าง

ระบบสร้างบัญชีและประกาศทักษะตัวอย่างอัตโนมัติเมื่อฐานข้อมูลยังว่าง

- สมาชิก: `demo@chronoswap.local` / `Swap@2026`
- ผู้สอนด้านออกแบบ: `mentor.design@chronoswap.local` / `Swap@2026`
- ผู้สอนด้านดนตรี: `mentor.music@chronoswap.local` / `Swap@2026`
- ผู้ดูแล: `admin@chronoswap.local` / `Admin@2026`

สมาชิกตัวอย่างแต่ละบัญชีเริ่มต้นด้วยเครดิต 2 ชั่วโมง คำขอใหม่จะอยู่สถานะรอผู้สอนตอบรับ เมื่อผู้สอนรับคำขอแล้วจึงนัดเรียน และหลังเรียนทั้งสองฝ่ายกดยืนยันเพื่อโอนเครดิต

ผู้ดูแลเข้าสู่ระบบด้วย `admin@chronoswap.local` / `Admin@2026` แล้วเลือกเมนู **ผู้ดูแล** เพื่อดูภาพรวมและจำนวนข้อพิพาท ค้นหาสมาชิกได้จากชื่อ อีเมล หรือคณะ และค้นหาประกาศได้จากชื่อทักษะ ผู้สอน หรือหมวดหมู่ ผู้ดูแลระงับ/เปิดใช้งานบัญชีสมาชิก ปิด/เปิดประกาศทักษะ และตัดสินข้อพิพาทได้ การระงับบัญชีจะยกเลิกคำขอที่ยังดำเนินการอยู่ของบัญชีนั้น และออกจากระบบทุกเซสชัน

แผงผู้ดูแลเก็บประวัติ 50 การกระทำล่าสุดไว้ในฐานข้อมูล โดยบันทึกผู้ดำเนินการ เวลา และรายการที่จัดการ เช่น การระงับสมาชิก การเปลี่ยนสถานะประกาศ และผลตัดสินข้อพิพาท

## กติกาเครดิตและกิจกรรม

- สมาชิกใหม่ได้รับ 2 ชั่วโมง เครดิตสะสมได้สูงสุด 20 ชั่วโมง และยอดคงเหลือติดลบไม่ได้
- ใช้เครดิตตามเวลาที่นัดหมาย เพิ่มครั้งละ 30 นาที
- เครดิตถูกกันไว้เมื่อส่งคำขอ แต่โอนจากผู้เรียนไปยังผู้สอนเมื่อทั้งสองฝ่ายยืนยันกิจกรรมเสร็จ
- สมาชิกยกเลิกคำขอที่ยังดำเนินการอยู่ได้ ผู้สอนรายงานกรณีไม่มาตามนัดหลังเวลาจบกิจกรรม และระบบชดเชยได้ไม่เกิน 30 นาทีโดยไม่ทำให้ยอดติดลบหรือเกินเพดาน
- กรณีเห็นไม่ตรงกัน สมาชิกส่งให้ผู้ดูแลตรวจสอบได้
- รีวิวเปิดให้เมื่อกิจกรรมเสร็จสมบูรณ์
- เพิ่มหรือเปลี่ยนรูปโปรไฟล์ได้จากหน้าโปรไฟล์ ระบบย่อรูปและเก็บไว้ในฐานข้อมูล

## ฟีเจอร์สมาชิกและการดูแลชุมชน

- **การแจ้งเตือน:** แจ้งเมื่อมีคำขอเรียนใหม่ ผู้สอนตอบรับ/ปฏิเสธ มีข้อความใหม่ หรือใกล้ถึงเวลานัดภายใน 24 ชั่วโมง การแจ้งเตือนจะปรากฏเมื่อสมาชิกออนไลน์
- **แชท:** ผู้เรียนและผู้สอนคุยกันจากบัตรกิจกรรมได้ตั้งแต่คำขอรอการตอบรับจนกิจกรรมเสร็จ เพื่อหารือหัวข้อและเวลา
- **ปฏิทินและเวลาซ้อน:** เปิดจากเมนูปฏิทิน ระบบแสดงคำขอและนัดหมายรายเดือน และปฏิเสธคำขอใหม่ที่เวลาซ้อนกับคำขอหรือนัดหมายที่กำลังดำเนินการของผู้เรียนหรือผู้สอน
- **รายงาน:** รายงานสมาชิกหรือประกาศได้จากหน้าคำขอ/ประกาศ รายงานจะเข้าหน้าแอดมินเพื่อตรวจสอบและทำเครื่องหมายว่ากำลังตรวจ ปิดเรื่อง หรือไม่รับรายงาน
- **อีเมล:** บัญชีใหม่ต้องยืนยันอีเมลก่อนลงประกาศ ส่งคำขอ แชท หรือส่งรายงาน ตั้งค่า SMTP เพื่อให้ระบบส่งลิงก์ยืนยันและลิงก์เปลี่ยนรหัสผ่านจริง
- **ส่งออกและสำรอง:** สมาชิกดาวน์โหลดข้อมูลบัญชี เครดิต กิจกรรม และแชทเป็น JSON ได้ ส่วนแอดมินดาวน์โหลดสำเนาฐานข้อมูล SQLite ได้จากหน้าผู้ดูแล ควรเก็บไฟล์สำรองไว้นอกเครื่องเซิร์ฟเวอร์ด้วย

## ตั้งค่าอีเมล

กำหนดตัวแปรต่อไปนี้ในสภาพแวดล้อมของเซิร์ฟเวอร์ก่อนเริ่มโปรแกรม:

```powershell
$env:CHRONOSWAP_SMTP_HOST = "smtp.example.com"
$env:CHRONOSWAP_SMTP_PORT = "587"
$env:CHRONOSWAP_SMTP_USER = "บัญชีส่งอีเมล"
$env:CHRONOSWAP_SMTP_PASSWORD = "รหัสผ่าน SMTP หรือ app password"
$env:CHRONOSWAP_EMAIL_FROM = "noreply@example.com"
$env:CHRONOSWAP_PUBLIC_URL = "https://ชื่อโดเมนของคุณ"
$env:CHRONOSWAP_DEV_EMAIL_LINKS = "0"
python server.py
```

พอร์ต 587 ใช้ STARTTLS และพอร์ต 465 ใช้ TLS โดยตรง อย่าใส่รหัสผ่าน SMTP ลงใน GitHub สำหรับการทดลองบน `127.0.0.1` หากยังไม่ตั้ง SMTP ระบบจะแสดงลิงก์ทดสอบในหน้าเว็บแทน; ปิดทางนี้เมื่อเปิดใช้งานบนเซิร์ฟเวอร์สาธารณะ

การขอเปลี่ยนรหัสผ่านตอบข้อความเดียวกันไม่ว่าอีเมลนั้นจะมีบัญชีหรือไม่ และลิงก์ตั้งรหัสผ่านหมดอายุใน 1 ชั่วโมง ส่วนลิงก์ยืนยันอีเมลหมดอายุใน 24 ชั่วโมง

## เปลี่ยนรหัสผ่านหรือเตรียมผู้ดูแล

เปลี่ยนรหัสผ่านบัญชีใดก็ได้จากหน้าต่างเซิร์ฟเวอร์:

```powershell
python server.py --change-password demo@chronoswap.local
```

สร้างบัญชีผู้ดูแลเพิ่ม:

```powershell
python server.py --create-admin
```

## ทำงานร่วมกันผ่าน GitHub

เมื่อเพิ่มเพื่อนเป็น collaborator แล้ว ให้เพื่อน clone รีโพและสร้าง branch แยกสำหรับงานของตัวเอง จากนั้นส่ง Pull Request เพื่อทบทวนและรวมโค้ดเข้ากับ branch หลัก ฐานข้อมูลใน `data/` จะไม่ถูกอัปโหลด แต่ละคนจึงมีฐานข้อมูลทดลองในเครื่องของตัวเอง และควรส่งเฉพาะโค้ดกับเอกสารขึ้น GitHub

สำหรับการทดลองในเครื่อง เว็บ bind เฉพาะ `127.0.0.1` และข้อมูลตัวอย่างเปิดไว้ตามค่าเริ่มต้น หากจะนำไปเปิดให้ผู้อื่นเข้าถึง ให้ใช้ฐานข้อมูลใหม่ ตั้ง `CHRONOSWAP_SEED_DEMO=0` ก่อนเริ่มครั้งแรก สร้างผู้ดูแลด้วยคำสั่งด้านบน และใช้ HTTPS พร้อมตั้ง `CHRONOSWAP_COOKIE_SECURE=1` หลังพร็อกซี HTTPS นอกจากนี้ให้ตั้งรหัสผ่านผู้ดูแลที่คาดเดายาก

ตัวแปรที่ตั้งได้:

- `CHRONOSWAP_HOST` — ค่าเริ่มต้น `127.0.0.1`
- `CHRONOSWAP_PORT` — ค่าเริ่มต้น `8000`
- `CHRONOSWAP_DB` — พาธไฟล์ SQLite; ค่าเริ่มต้น `data/chronoswap.sqlite3`
- `CHRONOSWAP_SEED_DEMO` — ตั้งเป็น `0` เพื่อไม่สร้างบัญชีและข้อมูลตัวอย่าง
- `CHRONOSWAP_COOKIE_SECURE` — ตั้งเป็น `1` เมื่อให้บริการผ่าน HTTPS

เว็บนี้เป็นต้นแบบสำหรับชุมชนขนาดเล็กที่ใช้เซิร์ฟเวอร์เดียวและฐานข้อมูล SQLite ไม่มีระบบชำระเงินจริงหรือวิดีโอคอลในตัว
